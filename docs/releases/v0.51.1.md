# TradeHelp 0.51.1

Squashed a couple bugs! This update connects decision reviews, practice, and evidence-based coaching.

## What's New

- **Decision reviews:** supporting trades, plan-versus-execution comparisons, previous-period counts, and followed/missed/unresolved commitment results. Missing records remain unknown, not automatic rule breaks.
- **AI Coach:** question-specific symbol/account/date context, cited trade links, explicit sample coverage, and editable memory saved only with your approval. Replies that fail reference checks use a labeled factual fallback. These checks do not guarantee every model interpretation is correct.
- **Privacy:** excluding written journal data from cloud requests also excludes approved memory and prior chat. Your current question and structured trade data still go to the selected provider. Ollama processing remains local.
- **Playbook practice:** answer before revealing the recorded trade, then self-assess your reasoning. Requires a linked trade with a plan screenshot locked before its recorded entry. Practice is not a prediction score.
- **Journal:** full-width history and a resizable entry/edit pane that keeps drafts when closed.
- **Navigation:** grouped workflows, collapsible market ticker, and expandable secondary statistics.
- **Mac release repair:** corrects the build tool's temporary signing-keychain password handling. Supersedes the unpublished 0.51.0 build; signing and notarization remain required.

## Downloads

- **Windows:** `TradeHelp-Setup.exe`
- **macOS, Intel and Apple Silicon:** `TradeHelp-Setup.dmg`. Universal app with separate native SQLite modules checked for both architectures. The ZIP supports automatic updates.
- **Linux:** `TradeHelp-Setup.AppImage`

Publication requires successful builds for all three platforms and all 10 installer, blockmap, and update-manifest assets. Separate mobile work in progress is not included.

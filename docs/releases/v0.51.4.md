# TradeHelp 0.51.4

Continue your AI Coach review without repeating which session you mean.

## AI Coach

- Answer follow-up questions while keeping the current session in focus. Mentioning its symbol or account no longer starts a broader review.
- The coach receives recent conversation context, including its previous question. Historical replies remain separate from current journal evidence.
- Start a different review by asking for it. Changes to filters, models or privacy settings separate the conversation context.
- If a reply cannot be validated, the retry message keeps the known session date.

Start a new session review after updating. Existing saved replies keep their original text.

- **Windows:** `TradeHelp-Setup.exe`
- **macOS, Intel and Apple Silicon:** `TradeHelp-Setup.dmg`. Automatic updates use the ZIP.

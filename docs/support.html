Mobile sync checklist

  1. Put the phone and desktop on the same private Wi-Fi network.
  2. Open Desktop Settings and start TradeHelp Mobile sync.
  3. Scan the pairing QR from Mobile Settings, then tap Pair and sync now.
  4. If pairing fails, confirm that the desktop firewall allows TradeHelp on private networks.
